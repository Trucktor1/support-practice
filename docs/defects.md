# Найденные дефекты
## D1 — синтаксис JSON в интеграционных тестах
Воспроизведение: запустить spotlessApply для исходного ApiTest. Форматтер сообщает ошибку синтаксиса строкового JSON в change и PUT.
Причина: кавычки JSON потеряли экранирование при генерации исходника.
Исправление: тела формируются ObjectMapper.writeValueAsString(Map.of(...)).
Регрессионные проверки: lifecycle и forbiddenOperationKeepsData компилируют и отправляют сформированные тела в REST API. Фактический результат запуска указывается в verification.md.
