# Проверка 17 ноября 2026 года
Новый проект создан с нуля в support-practice.
Java/Kotlin компилируются, bootJar собирается. Spotless форматирует исходники.
21 модульная проверка прошла без ошибок и пропусков: 16 Java и 5 Kotlin.
Mockito запускается с javaagent при старте JVM из-за ограничения динамического attach в локальной среде.

Интеграционные проверки требуют Docker API. В текущей песочнице доступ к named pipe Docker запрещён (permission denied). Поэтому работа PostgreSQL API, Dockerfile, backup/restore, перезапуск и сквозные сценарии пока не подтверждены локальным успешным запуском.
Подготовлены 6 PostgreSQL-интеграционных и 2 сквозных сценария. Запуск всех проверок: gradlew.bat check jacocoTestReport bootJar.
Подготовлена конфигурация CI/CD. Успешный запуск pipeline, публикация образа, стенд и откат пока не подтверждены. URL успешного pipeline и идентификатор доставленного образа отсутствуют.
Полное выполнение ТЗ требует завершить эти проверки и доставку на учебный стенд.
